# Volunteer Vista

**Volunteer Vista** is a full-stack web application designed to connect volunteers with organizations that need help. It enables users to discover, apply for, and manage volunteer opportunities, while also giving organizations the tools to post and track volunteer projects.

## 🌐 Live Demo

Visit the live application: [Volunteer Vista](https://volunteer-vista-server.vercel.app)

---

## 🛠️ Tech Stack

### 🔹 Frontend
- **React** – Component-based UI development
- **Vite** – Fast front-end build tool
- **React Router** – Client-side routing
- **Tailwind CSS** – Utility-first CSS framework

### 🔹 Backend
- **Node.js** – JavaScript runtime environment
- **Express.js** – Backend web framework
- **MongoDB** – NoSQL database
- **Mongoose** – ODM for MongoDB

### 🔹 Authentication
- **Firebase Authentication** – User login and signup management

---

## 🔑 Features

- 🔐 Secure Firebase Authentication
- 📄 CRUD operations for volunteer opportunities
- 📋 Role-based dashboard (User / Organization)
- 📱 Responsive design for mobile & desktop
- 🔎 Search and filter opportunities
- 📌 Application tracking for volunteers

## 🚀 Installation Process

### Prerequisites

- Node.js and npm installed
- MongoDB instance (local or cloud e.g., MongoDB Atlas)

Follow these steps to run the project locally:

### 1. Clone the Repository

```bash
git clone https://github.com/SangramBishwas/volunteer-vista-server.git
cd volunteer-vista-server

```

### 2. Setup
```bash
npm install

```
